# パイプロイド タワーバトル Version 3

[Version 3であそぶ](https://koto-share.github.io/piperoid-tower-battle/v3/)

PC・スマートフォン対応。17体・51ポーズ。ノーマルモード（同じ端末で2人対戦）とコンピュータモード（強さ3段階）から選べます。通常対戦・軽い重力のふわふわ対戦・落下3秒後に固定するガチガチ対戦に対応。前のキャラが接触したら、静止を待たずに次を落とせます。ゲームオーバー時の写真と停止した最終状態も確認できます。
